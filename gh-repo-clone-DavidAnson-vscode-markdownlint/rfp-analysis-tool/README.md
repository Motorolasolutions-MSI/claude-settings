# Heavyweight Air RFP Bid Analysis Tool

A complete toolkit for quickly and accurately analyzing multiple logistics suppliers' heavyweight air freight RFP bids. Includes a Python analysis engine with weighted scoring, cost normalization, and risk assessment, plus an interactive HTML dashboard for visualization.

## Quick Start

### 1. Run the Analysis (Python — no external dependencies needed)

```bash
cd rfp-analysis-tool
python3 analyze_bids.py
```

This processes the sample data and generates reports in `output/`.

### 2. Open the Interactive Dashboard

Open `dashboard.html` in any web browser. You can either:

- **Load demo data** — click "Load Demo Data" for an instant preview
- **Upload results** — upload the `output/analysis_results.json` generated by the Python script

## How It Works

### Evaluation Criteria (Weighted Scoring)

| Category | Default Weight | What It Measures |
|---|---|---|
| **Total Cost** | 35% | All-in cost per kg (base + fuel + security + peak surcharges) |
| **Transit Time** | 15% | Volume-weighted average transit days |
| **Reliability** | 15% | On-time %, damage rate, claims ratio |
| **Capacity** | 10% | Weekly capacity + scalability score |
| **Qualitative** | 15% | Financial stability, technology, customer service |
| **Contract Flexibility** | 10% | Min commitment, escalation cap, term length, exit notice |

All weights are adjustable in real-time via the dashboard sliders, or by editing `data/evaluation_weights.json`.

### Analysis Pipeline

1. **Data Loading** — reads standardized bid CSV, volume profile, and weight config
2. **Cost Calculation** — computes all-in cost per kg for each lane/weight-break, then calculates total annual cost using your actual volume profile
3. **Scoring** — normalizes each dimension to 0–100, then applies weights
4. **Risk Assessment** — flags low on-time performance, high damage/claims, unfavorable contract terms, capacity gaps
5. **Report Generation** — produces CSV reports and JSON for the dashboard

## Using Your Own Data

### Step 1: Prepare Bid Data

Use `data/rfp_template.csv` as your RFP template. Each supplier fills one row per lane/weight-break combination with these fields:

| Field | Description |
|---|---|
| `supplier_name` | Supplier company name |
| `lane_origin` | Origin airport code (e.g., JFK) |
| `lane_destination` | Destination airport code (e.g., LHR) |
| `weight_break_kg` | Weight break in kg (e.g., 500, 1000, 2000) |
| `rate_per_kg` | Base rate per kg in USD |
| `fuel_surcharge_pct` | Fuel surcharge as % of base rate |
| `security_surcharge_per_kg` | Security surcharge in USD per kg |
| `peak_surcharge_pct` | Peak season surcharge as % of base rate |
| `min_transit_days` / `max_transit_days` | Transit time range in days |
| `capacity_kg_per_week` | Weekly capacity on this lane |
| `on_time_pct` | Historical on-time delivery percentage |
| `damage_rate_pct` | Historical damage rate percentage |
| `claims_ratio_pct` | Historical claims ratio percentage |
| `financial_stability_score` | 1–10 rating |
| `technology_score` | 1–10 rating (EDI, API, tracking) |
| `customer_service_score` | 1–10 rating |
| `scalability_score` | 1–10 rating |
| `min_volume_commitment_kg` | Minimum annual volume commitment |
| `rate_escalation_cap_pct` | Maximum annual rate increase % |
| `contract_term_months` | Contract duration |
| `exit_notice_days` | Required exit notice period |

### Step 2: Update Volume Profile

Edit `data/volume_profile.csv` with your actual annual shipment volumes per lane and weight break.

### Step 3: Adjust Weights (Optional)

Edit `data/evaluation_weights.json` to change the importance of each evaluation category. Weights are automatically normalized.

### Step 4: Run Analysis

```bash
python3 analyze_bids.py --bids data/your_bids.csv --volume data/your_volumes.csv
```

### Step 5: Review Results

- Open `dashboard.html` and upload `output/analysis_results.json`
- Or review the CSV reports in `output/` directly in Excel/Google Sheets

## Dashboard Features

- **🏆 Supplier Rankings** — sortable table with all scores
- **📊 Score Breakdown** — horizontal bar charts for each scoring dimension
- **💰 Cost Analysis** — total annual cost comparison + per-lane rate comparison with spread %
- **⚠️ Risk Assessment** — risk cards per supplier with severity badges
- **📋 Contract Comparison** — side-by-side contract terms
- **⚖️ Interactive Weights** — adjust evaluation weights with live score recalculation

## Requirements

- **Python 3.6+** (standard library only — no pip installs needed)
- **Any modern web browser** for the dashboard (Chrome, Firefox, Safari, Edge)
